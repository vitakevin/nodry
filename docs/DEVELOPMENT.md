# 别太干巴了 · 首版开发规格

## 范围

Tauri 2 + React + TypeScript + Rust + SQLite。本地使用，不登录、不上传饮水数据、不调用大模型。主窗口内完成配置、记水和设置；关闭窗口后留在菜单栏／托盘，明确退出后停止提醒。Mac保留Dock图标，点击Dock或再次打开应用会恢复主窗口；即使裂纹层仍可见，也必须响应Reopen并恢复主窗口。菜单栏／托盘菜单提供“打开应用 / 修改设置”入口。

首版仅提供体重（正整数斤）、上下班时间、登录启动和屏幕特效开关。不开设历史统计、云同步、悬浮球、桌宠、排行榜、皮肤或自动更新。

## 数据与计分

- 目标整数单位：`weightJin * 1750`，一个单位为0.01mL。
- 截止为下班时间与19:00的较早者；不支持跨日工作时段。
- 时段从上班时刻起每小时一段，尾段按实际时长分配；使用最大余数法保证整数合计精确等于目标。
- `expected = target * clamp((now-S)/(E-S),0,1)`；`hourly = target * 3600000/(E-S)`；`dryness = min(100,max(0,expected-actual)/hourly*50)`。
- 数字两位小数，内部和字号保留精度。字体沿指数曲线变化，限制最大宽度。
- 饮水记录包含唯一ID、整数水量、毫秒时间戳和记录当时的本地日期。SQLite事务写入，重复ID幂等。
- 同日时段外记录仍计入当天；修改设置保留真实记录；跨日重新汇总。记录日期不随后续时区变化迁移。

## 自适应提醒

| 分数 | 间隔 |
|---|---|
| 0 | 暂停 |
| 0 < 分数 < 50 | 60分钟 |
| 50 <= 分数 < 100 | 30分钟 |
| 100 | 15分钟 |

提醒、成功记水、暂不喝、修改配置推进计时锚点。0分预付水量缓冲结束时，按真实欠水开始时刻重新等待。下次提醒同时计算未来50/100分切换，避免预估时间错误。

后台单实例统一调度，不依赖界面动画。启动／唤醒最多发送当前一次，不补发整串历史提醒。提醒声明先持久化，系统通知为尽力交付：进程在声明和系统交付之间退出，可能跳过当次，不能宣称操作系统通知严格一次送达。

## 干裂

有效工作时段内，主显示器的透明覆盖层从右下角铺开半透明土地，并显露固定的不规则闭合土块。1分起可见，小数分数参与渲染。增长曲线仍为每分生长率的积分，0—20、20—50、50—80、80—100分相对生长率为1、2、3、4；20、50、80分处覆盖范围和缝宽连续，100分达到最大范围。

土块由固定种子的140个站点生成Voronoi分区，共用边界以形成闭合网格；共享边轻微不规则化，避免整齐砖块或树枝状路径。相邻土块向内收缩形成真实缝隙，右下角的旧裂缝更宽，扩展前沿较细。屏幕边缘的土块保持延伸到屏幕外，避免形成深色边框。土色采用浅土黄、赭色，缝隙深褐色，土块使用内置干土WebP材质提供颗粒和斑驳，不透明度最高52%，裂缝最高85%。

立体层使用WebGL：从固定土块边界一次性生成距离场，逐帧只传入当前生长进度。高度场采用中心较低、边缘抬高的薄泥片轮廓，分数越高翘边越明显；用表面法线、方向性光照、泥土侧壁及短投影体现高度。边界有更密的破碎细节，裂缝宽度整体收细并保留变化，避免大块平板和均匀描边。渲染像素上限约200万，不另启永久动画循环。WebGL不可用或上下文丢失时回退到基础SVG土地效果；上下文恢复后重建资源。

不加界面渐变或额外文案，运行时不调用图片或AI服务。材质及生成提示词见`src/assets/README.md`。

后台每秒发送当前分数，前端在更新间插值全局进度，覆盖范围、缝宽及不透明度共用同一动画值；降低分数时土块沿同一几何布局合拢，土地退回右下角，0分完全清空。鼠标穿透、不抢焦点。关闭特效、工作时段结束后隐藏；开启或重启后根据当前分数恢复。不限制每天一次，不播放5秒自动消失动画。

覆盖层先订阅事件，再通过仅裂纹窗口可访问的接口取得初始分数，后台收到就绪握手后才显示。该接口不返回体重或饮水记录。持续裂纹不写入提醒声明、不改变普通提醒锚点；原有通知频率不变。旧数据库的每日裂纹标记保留兼容，不再用于限制显示。

## 开发演示

`npm run dev` 后访问 `http://127.0.0.1:1420/?demo=1`。显示明确标记，使用单独的浏览器演示存储和可控时钟，无真实桌面通知；该入口不是后台提醒的验证结果。

## 构建与验收

- `npm ci`、`npm test`、`npm run build`
- `cargo test --manifest-path src-tauri/Cargo.toml --lib`
- `npm run tauri dev`
- Mac：`npm run tauri build -- --bundles dmg`
- Windows：在Windows上运行 `npm run tauri build -- --bundles nsis`

GitHub Actions分别生成Apple Silicon、Intel、Windows x64测试安装包，不自动建立公开Release。

正式发行需替换Mac临时签名并完成Developer ID签名、公证；Windows配置Authenticode签名。构建成功与真实系统验收分别记录，Windows通知必须安装后验证。
